🔐 Encrypted, not hosted

Every value is envelope-encrypted with a per-tenant data key. hikyo never stores a plaintext secret and neither does your database backup.

✅ Proof on every read

Access is proof-carrying: unauthorized is indistinguishable from nonexistent. No accidental enumeration, no leaky 403s. authorize() is the only door.

⚡ One binary, everywhere

Point your app at hikyo and run. hikyo run -- ./server injects the right env, hikyo render writes a file, hikyo doctor tells you what's missing.

◆ Envelope encryption

Per-tenant data keys wrap every value. Your DB never sees a plaintext secret — render/run decrypt only in memory, only after authorize.

◆ Proof-carrying access

Unauthorized ≡ nonexistent. Every read carries a proof through one chokepoint — no enumeration, no leaky errors, no bypass path.

◆ Reproducible & signed

Releases are cosign-signed with an SBOM and offline trust. hikyo doctor verifies the binary you're running is the one that was built.
